# Rock-Paper-Scissors ✊ 🖐 ✌
<p align="center"><img src="readme_img/menu.png" alt="Menu screenshot" width="80%"></p>
  

<p align="center">A game where you risk your life playing rock paper scissors against a killer machine</p>

# Features
<p align="center"><img src="readme_img/menu.png" alt="Game screenshot" width="80%"></p>

- Rich 2010s horror ambience
- Functional AI
- Textures
- Sound
- Video encoding with FFmpeg onto frames readable by SDL

# Compiling and running
<p align="center"><img src="readme_img/menu.png" alt="Visual Studio screenshoot" width="80%"></p>
<p align="center">To compile and run the project open the Game.sln file and do it through Visual Studio</p>

# Dependencies
- SDL2
- SDL_Image
- SDL_Mixer
- FFmpeg
